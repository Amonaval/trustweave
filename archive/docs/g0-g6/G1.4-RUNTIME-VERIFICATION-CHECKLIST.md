# G1.4 — High-Level Runtime Verification

No Supabase migration is required for G1.4.

After applying the code patch, a short smoke check is enough:

1. Open an existing Family and confirm Home/Family load normally; switch Family once if you have multiple networks.
2. Open Founder Launch Control / Playground and toggle **Build family together** OFF → ON once. It must not show `Unknown feature key`; if the backend is behind, the control should instead show `Database update required` from the G1.3 protection.
3. Confirm Platform Owner / Launch Control data loads normally and one rollout/Playground control can still be changed.
4. Reload once and glance at the browser console for remote import, active-network, Launch Control, or feature-registry errors.

If these pass, G1.4 has no additional user-facing workflow to regression-test.
