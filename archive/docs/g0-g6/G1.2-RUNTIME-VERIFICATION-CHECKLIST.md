# G1.2 — Quick Runtime Verification Checklist

G1.2 is architecture-only, so a short smoke pass is sufficient. No database migration is required.

## 5-minute high-level check

1. **Normal Family login**
   - Open an existing family.
   - Home, Family, Find family, Me and Explore & Guide should appear exactly as before.

2. **Experience levels**
   - As a normal member, switch Simple → Connected → Explorer.
   - Simple stays minimal; Connected adds memories/moments; Explorer adds the wider member feature set.
   - No feature should unexpectedly disappear or become newly visible.

3. **Admin-only behavior**
   - Open Family Admin as Owner/Admin.
   - Manage family / Import family / Approvals & history remain admin-only.
   - A normal member must not gain these controls.

4. **Founder Launch Control**
   - Open Launch Control as platform owner.
   - Existing feature names and current rollout states should be unchanged.
   - Specifically verify `Build family together` still shows its existing Pilot/default behavior and Community remains at its existing rollout state.
   - Do not change states just for this check unless you intend to test rollout writes.

5. **Playground**
   - Open anonymous Sample Family / Playground.
   - The showcase should still expose the broad demo feature set independently from real-family rollout.
   - It must remain read-only/no-save.

6. **What's New / announcements**
   - If an existing feature announcement is pending, its Family label/description should render normally.
   - No Alumni feature should appear anywhere.

7. **Browser console**
   - Reload once and confirm there is no `Unknown feature key`, missing feature definition, or vertical registry error.

## What does NOT need checking for G1.2

- Supabase migrations: none added.
- Family data integrity: no entity/relationship persistence changed.
- S3-A1 intake behavior: untouched.
- Invitations/claiming: untouched.
- Mobile layout translations: no UI/copy/layout changed in this mission.

## Fast acceptance rule

If existing Family navigation, experience-level visibility, Admin controls, Founder Launch Control and Playground all look identical and the browser console is clean, G1.2 has passed the practical runtime smoke check.
