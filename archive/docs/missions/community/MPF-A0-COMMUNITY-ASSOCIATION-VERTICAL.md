# MPF-A0 — Community / Association Vertical Foundation

## Mission
Activate a reusable Community / Association vertical from the existing template proof, driven by a real family-centered association pilot while keeping all implementation generic.

## Product model
The association is the network. Its primary membership unit may be a **family / household** represented by one person, with spouse/children or other people represented as first-class entities when needed. This is not a giant Family Tree and it is not an Alumni network.

## V1 capabilities
- Community / Association network creation
- household/family primary entity
- representative/member and committee relationship semantics
- membership year + membership status for annual renewal
- directory and configurable structure projections
- shared events + RSVP
- memories/history and media capability
- announcements/updates and milestones
- groups/committees/circles
- governed contributions
- Launch Control and Playground
- 10-family MPF-like generic sample dataset

## Deliberate boundary
Formal elections are **not** implemented by relabeling a casual poll. Election-grade voting requires a later governed capability covering eligibility, one eligible vote, ballot/privacy mode, election window, tamper resistance, results and audit evidence.

## Reuse doctrine
The implementation uses the existing productized-template runtime, shared activity engine, generic entities/relationships, Launch Control, import, claiming and invitation infrastructure. No MPF-specific table or business rule is introduced.

## Pilot intent
The first real network can be configured as MPF East and onboard 5–10 families by link. Product enhancements should come from real pilot evidence and then be generalized into the Association vertical.
