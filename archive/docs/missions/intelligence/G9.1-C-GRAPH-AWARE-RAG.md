# G9.1-C — Graph-Aware RAG

## Mission
Combine verified Network OS graph truth with authorized organizational evidence without changing the certified G9 deterministic engine or the standalone Knowledge Hub runtime.

## Delivered
- Organization-only graph-aware intelligence orchestration.
- Four first-class intents: expertise, ownership, dependency, architectural decision/rationale.
- Directed `owns` and `depends_on` graph traversal in a new orchestrator rather than modifying G9.
- Verified skill matching for expertise questions.
- Authorized evidence retrieval from active-network, network-visible evidence only.
- Verified assertions are surfaced only when backed by at least one network-visible evidence record.
- Visible answer confidence, provenance/freshness and graph/evidence reasons.
- Optional Knowledge Hub sidecar query adapter; no changes to existing Knowledge Hub query, vector, Electron or API runtime.
- Organization live runtime uses the new experience; Playground and every other vertical continue using the original G9 Intelligence Center.

## Safety boundary
`Graph truth -> deterministic reasoning -> authorized evidence enrichment -> optional synthesis`.
Retrieval and synthesis never mutate graph truth. Restricted evidence is excluded before the answer path.

## Initial supported questions
1. Who knows X best?
2. Who owns X?
3. What depends on X / what does X depend on?
4. Why did we choose X?

## Deferred intentionally
- LLM synthesis UI/provider execution is optional and remains disabled by default.
- Perfect source-system ACL mirroring remains outside G9.1-C; only network-visible evidence participates.
- Risk scoring and gap-to-action belong to G9.1-D.
