# G9 — Network Intelligence Layer

## Mission
Turn the Generic Network OS from a system that stores/explores networks into a system that helps people make better decisions from the network they are already authorized to see.

## Product promise
**Find → Understand → Connect → Act → Capture → Improve.**

G9 is not a generic chatbot. It is a permission-aware intelligence layer built over entities, affiliations, typed relationships and network activity.

## Shared deterministic engines
1. **Network Search / Discovery** — matches names, metadata and affiliation dimensions.
2. **Connection Intelligence** — shortest known typed paths and structurally important connectors.
3. **Network Health / Completeness** — affiliation completeness, isolated entities and concentrated connectivity.
4. **Missing-link Detection** — flags entities with strong shared context but no known direct relationship. It never invents a relationship.
5. **Evidence-backed Ask Network** — converts common buyer questions into deterministic network queries and always surfaces evidence/confidence.

## Five-vertical product proof
### Family
- information gaps and isolated relatives
- shared city/profession/generation context
- structurally useful family connectors
- evidence-backed family questions without broadening privacy

### Alumni
- cohort/city/company discovery
- connector and warm-path reasoning
- mentoring/introduction opportunities
- network completeness and missing context

### Organization
- expertise discovery
- high-connectivity / knowledge-concentration signals
- ownership/dependency context through typed relationships
- missing-link opportunities across teams/projects/skills

### Business Trust
- trusted-context discovery
- warm-path / introduction reasoning
- network evidence and provenance
- relationship gaps where suppliers/businesses share meaningful context

### Franchise
- peer-location discovery
- cross-location operating knowledge paths
- strongest network connectors
- coverage/relationship gaps across geography, ownership and operating context

## Safety and privacy contract
- tenant-isolated input only
- uses the same already-authorized data loaded by the vertical
- no new unrestricted server read path
- deterministic first
- evidence visible to the user
- confidence shown
- no inferred relationship is persisted
- no unrestricted network data is sent to an LLM

## Launch strategy
Migration `049_g9_network_intelligence.sql` registers all five Intelligence features in **Test** for real networks and enables them in every Playground. Platform owners can promote the `intelligence` bundle through Launch Control independently per vertical.

## Deliberate non-goals for G9
- no opaque universal trust score
- no generative model as the source of truth
- no embedding/vector infrastructure yet
- no new cross-tenant data sharing
- no autonomous writes based on intelligence
- no G10 commercial foundation before real pilot evidence

## G9 closure criteria
- deterministic engine contracts implemented
- Intelligence surface in all five active verticals
- evidence-backed Ask Network
- Health + connector + missing-link insights
- Guide + Playground + Launch Control coverage
- migration registration
- historical gates preserved
- runtime verification checklist supplied
