# NF-0A / FD-2 — Federation as Distribution Supernode

**Status:** Foundation implementation complete; real affiliation persistence intentionally deferred to NF-1/NF-2.

## Mission
Turn federation from a purely structural architecture concept into a measurable distribution mechanism: one trusted umbrella/association can activate many independently governed child networks without receiving implicit person-level access.

## Why this matters
A solo founder cannot sustainably win a feature-copying race against mature software companies. Distribution supernodes shift the advantage toward assets competitors cannot instantly reproduce: organizer trust, embedded institutional workflows, dense governed networks and downstream network activation.

## Product invariant
**Federation is distribution leverage, never a privacy shortcut.**

- Network affiliation ≠ data access.
- Network participation ≠ person participation.
- Application participation ≠ global visibility.
- Private graph topology remains private.
- M6 peer trust bridges remain semantically separate from NF umbrella affiliation.

## Implemented foundation
1. Added neutral federation relationship/privacy contracts under `core/federation`.
2. Added aggregate-only deterministic **Network Multiplication Potential** scoring.
3. Added synthetic Community, Alumni and Business umbrella scenarios.
4. Added launch-controlled **Federation Distribution Lab** to My Networks.
5. Added a separate `federation` Launch Control bundle and TEST-by-default rollout flag for all six verticals.
6. Added migration `069_nf0_federation_distribution_supernode.sql`.
7. Added source validation gate `validate:nf0a`.

## What the score measures
The initial deterministic score uses only institution/network-level aggregates: child-network count, organizer reach, governance readiness, data readiness, domain fit and adjacent-network referral multiplier. It deliberately needs no member profiles or private relationship edges.

## What this mission does NOT do
- It does not create Network↔Umbrella persistence.
- It does not enroll people into umbrellas.
- It does not expose private member data.
- It does not reuse M6 bridge edges as federation affiliation.
- It does not launch NF-3+.

## Next structural missions
- **NF-1 — Network Passport / Federated Profile**: explicit outward network identity and publication scopes.
- **NF-2 — Governed Network↔Umbrella Affiliation**: request/approve/suspend/revoke many-to-many affiliation.

Only after those are sound should the Distribution Lab consume real federation data.

## Anti-cloning result
If a competitor copies this visible scorecard, they still do not possess the organizer relationships, seeded child networks, governed affiliation history, onboarding workflow, verified provenance or outcome history. The mission is valuable only if it accelerates accumulation of those assets.
