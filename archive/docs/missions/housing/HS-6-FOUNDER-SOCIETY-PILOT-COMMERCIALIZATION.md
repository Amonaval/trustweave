# HS-6 — Founder Society Pilot & Commercialization

## Mission goal
Turn the source-complete Housing Society vertical into a measurable, repeatable founder-led pilot and commercialization proof.

## Implemented
- Pilot A/B/C/D lifecycle with target unit cohort and status history.
- Objective readiness snapshot derived from HS-1→HS-5 records.
- Weekly operator checkpoints: admin hours saved, offline operations remaining, willingness-to-pay, renewal intent, repeatable onboarding and founder-specific-code flag.
- Product usage events scoped to the signed-in resident's current flat where available.
- Notice readership evidence.
- Complaint resolution, maintenance visibility, governance and security/compliance evidence.
- Pricing experiment history without hard-coded product pricing.
- Evidence JSON export.
- CSV import template + 30-unit synthetic sample.
- Founder pilot admin guide, resident guide, second-society onboarding runbook and pricing experiment playbook.
- Launch Control/feature-catalog entries for HS-6 pilot readiness, metrics and pricing.

## Commercialization gate
Pilot D is the decisive gate. A second society should onboard through the same product flows, mapped import, migrations and authorization model without founder-specific code or manual database patches.

These remain deferred until pilot evidence justifies them.
