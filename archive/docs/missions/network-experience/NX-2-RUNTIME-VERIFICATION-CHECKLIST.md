# NX-2 Runtime Verification Checklist

Use this only at the NX-2 milestone verification window.

## Family Home
- [ ] Open a non-simple Family Home and confirm **Living family → One meaningful family minute** appears without breaking the existing hero/digest/pulse.
- [ ] The daily card has a useful action and does not show blank/undefined text.
- [ ] Clicking a rediscovered/celebration relative opens the correct Family profile.
- [ ] A preservation action opens the existing governed contribution flow.
- [ ] A memory/history action goes to the correct existing surface.

## Generational connection
- [ ] **Across generations** shows sensible older/younger living members when birthdays exist.
- [ ] Sparse data produces a helpful fallback rather than a broken card.
- [ ] Family continuity counts look plausible for generations, cities and preserved context.

## Privacy / behavior
- [ ] Switching to another network does not carry Family names/details into that network.
- [ ] Playground remains read-only; NX-2 actions do not persist demo changes.
- [ ] No infinite feed, streak or gamification behavior is introduced.

## Responsive UX
- [ ] Desktop: daily + generations cards are balanced, not excessively tall.
- [ ] Tablet: cards stack cleanly.
- [ ] Mobile: generation bridge and continuity strip become single-column without horizontal overflow.

## Regression
- [ ] Family profile opens/closes normally.
- [ ] Memories, Participation, Tree and Quiet Digest still open normally.
- [ ] `npm run build` passes in the normal development environment.
