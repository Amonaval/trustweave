# QA Free-Tier POC profile

Default `npm run qa:certify` is now the low-cost POC profile. Full certification remains available as `npm run qa:certify:full` and must not be used routinely on Free Tier.

POC scope: Family + Housing Society, owner/member/tenantB, one worker, existing seed reuse, no volume/stress/destructive loops. RPC permission audit remains visible but advisory during POC; its findings are not suppressed.
