# G8.5-B Runtime Verification Checklist

- Open Organization, Business Trust and Franchise Playground.
- Confirm Directory cards open entity details.
- Confirm Explorer entity selection opens the same detail shell.
- Open Places and confirm the interactive map renders markers plus location coverage list.
- Click a map entity/location and confirm drill-down/navigation works.
- Open Connections and select two connected entities; confirm a shortest known path appears.
- Confirm relationship filter works; as admin, add/remove a relationship.
- Open Community as an ordinary/demo user; confirm Event, Story/History, Milestone and Announcement tabs are visible.
- Confirm RSVP remains disabled in read-only Playground and works in a writable network.
- Submit governed contributions using each intent category.
- As network admin, confirm Launch Control status is visible but cannot be mutated from Network Admin.
- Open Guide and confirm capability cards navigate to available surfaces.
- Confirm Light, Dark and Aurora remain usable on new shared surfaces.
- Confirm Family and Alumni navigation/runtime are unchanged.
- Run `npm ci && npm run build` in the normal local/CI environment.
- Run `npm run validate:g8` and `npm run validate:g8-5b`.
