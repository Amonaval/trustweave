# G8.5-A — Baseline Cleanup, Capability Audit & Reuse Guardrails

**Status: IMPLEMENTED**

## Mission goal

Prepare the G8 R4 baseline for capability-parity work without beginning another architecture generation.

G8.5-A performs three jobs:

1. remove historical Markdown clutter from the repository root without deleting project history;
2. repair the two missing G5 certification artifacts required by accepted historical baselines;
3. convert the observed cross-vertical product-depth problem into explicit architecture/product rules and a permanent source gate.

## Baseline cleanup

Historical Markdown files were moved into `archive/docs/` by generation/category. Accepted source manifests now point to those preserved archived paths.

The two G5 certification artifacts that were referenced by G6/G7/G8 accepted baselines but absent from the R4 ZIP were restored as historical compatibility artifacts under `archive/docs/g0-g6/`.

No product runtime or database schema change is introduced by this cleanup.

## Capability audit result

The five verticals are architecturally valid but not equally mature.

Family remains the strongest product implementation. Alumni has substantial product depth. Organization, Business Trust and Franchise use the shared G7/G8 foundations but several surfaces are still thinner generic representations.

The detailed audit is in `G8.5-A-CAPABILITY-APPLICABILITY-MATRIX.md`.

## New permanent rules

`GENERIC-CAPABILITY-UTILIZATION-RULE.md` establishes:

- reuse by default where semantics fit;
- explicit justification for applicable capabilities that are not consumed;
- extraction at the lowest semantically correct shared layer;
- a Productized Vertical Gate based on actual capability depth rather than routes/navigation alone;
- a Showcase rule requiring realistic enough Playground data to exercise the product.

## Scope intentionally deferred to G8.5-B/C

G8.5-A does **not** yet claim parity for maps, rich relationships, stories/history, contribution workflows, contextual Guide, Launch Control depth, notification/digest, media or richer construction UX in the three G8 business verticals.

Those are the implementation targets of G8.5-B, followed by richer five-vertical showcase/certification in G8.5-C.
