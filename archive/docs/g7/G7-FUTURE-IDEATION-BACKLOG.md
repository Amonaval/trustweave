## Unknown-future readiness checklist

A future vertical should be able to answer:

1. What entity types exist?
2. What dimensions can entities belong to?
3. What typed relationships exist?
4. Which shared capabilities apply?
5. Which domain policies/adapters are unique?
6. How should users explore the network?
7. What privacy/governance constraints exist?
8. What intelligence is valuable?

If a new idea can answer those questions, it should be possible to model it without rewriting platform Core.
