# G7 — Generic Network OS Productization & Template Architecture

**Execution mode:** one consolidated High-effort mission with internal workstreams.

## Workstream A — Generic affiliation / hierarchy model
- dimension definitions
- entity affiliations
- multiple projection definitions
- typed relationship contract
- compatibility adapters for Family/Alumni

## Workstream B — Capability catalog & template composition
- first-class template contract
- capability packs
- dependency validation
- Custom Network template skeleton

## Workstream C — Proven Family capability reuse
Audit every major Family feature against Alumni and future templates.

Priority candidates:
- Explorer
- Discovery / Search
- Groups
- Events / RSVP
- Memories / Media
- Maps
- Milestones
- Contributions
- Connection Paths
- Digest

## Workstream D — Rich Alumni proof
Use reusable engines to make Alumni a living institutional network:
- configurable institution/program/batch/stream explorer
- alumni memories
- reunions + RSVP
- chapters/groups
- geography
- contribution campaigns
- connection paths
- milestones/digest

## Workstream E — Future template architecture proofs
Create configuration/Playground models — **not full production products** — for:
1. Organizational Intelligence
2. Business Trust
3. Franchise
4. Education Graph
5. Custom Network

## Workstream F — Security / compatibility
- preserve Family + Alumni
- tenant isolation
- vertical feature ownership
- no cross-vertical imports
- additive migrations
- accepted-file preservation gates
