# NETWORK GROWTH FLYWHEEL & EXPERIMENT PLAN

## Primary hypothesis
The platform can reduce acquisition cost by onboarding trusted network anchors and using operators to create initial density.

## Flywheel
Anchor acquired
→ roster imported
→ volunteers activated
→ members claim profiles
→ useful workflows launched
→ successful outcomes captured
→ members invite others
→ adjacent networks join
→ community utility grows
→ organic acquisition increases

## Experiments

### Experiment A — Family/community activation
Target:
- one real community;
- 20–50 family networks or a meaningful subset;
- minimal seed data only;
- explicit organizer approval.

Measure:
- claim rate;
- invitation acceptance;
- contribution rate;
- requests posted;
- successful introductions;
- adjacent families added organically.

### Experiment B — Alumni
Launch a cohort/chapter with:
- mentoring;
- jobs/referrals;
- alumni journeys;
- events.

Measure outcome conversion, not feed activity.

### Experiment C — Franchise
Launch one brand/region with:
- 10–30 locations;
- operator help;
- playbooks;
- cross-location problem solving.

Measure repeated operational use.

### Experiment D — Organization
Launch one department/business unit with:
- expertise;
- ownership;
- dependencies;
- knowledge risk.

Measure decisions changed / time saved.

## Go / no-go thresholds
Do not set final numbers until real baseline data exists, but future experiments should define thresholds for:
- activation;
- time-to-value;
- successful outcomes;
- organic invites;
- retention;
- operator cost.

## Important distinction
Network effect is proven only when **existing networks/users materially reduce the cost of acquiring and activating new networks/users**.
