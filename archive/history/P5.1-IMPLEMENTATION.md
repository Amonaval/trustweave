# P5.1 Living Network — Implementation

Status: source implemented and production build verified on 2026-08-21.

The first D1 family UX remediation is documented in `P5.1-FAMILY-UX-AUDIT.md`.

## Delivered

- **CORE:** privacy-aware network timeline RPC and filtered timeline UI.
- **MODULE (family):** upcoming birthdays, marriages, family events and milestones; enabled only for the family template.
- **CONFIG:** administrator controls for safe-field direct self-edit and family milestones.
- **PRODUCT:** mobile-accessible Timeline navigation, upcoming widget, profile links and event filters.
- **Governance:** only profession, city, country, bio, phone, email and an account-owned photo can direct-save. Identity, lifecycle, visibility, status and relationships remain reviewed.

## Security and verification

Migration `015_p5_1_living_network.sql` owns enforcement. Both RPCs are `SECURITY DEFINER` with fixed `search_path`. The self-edit RPC derives the member from `auth.uid()`, checks configuration and accepts neither governed fields nor a target ID. Timeline rows are filtered before leaving PostgreSQL.

`npm ci`, `tsc --noEmit`, `npm run build`, and `node validate-demo.mjs` pass. Live staging migration and role-matrix verification still require a configured Supabase staging project.
