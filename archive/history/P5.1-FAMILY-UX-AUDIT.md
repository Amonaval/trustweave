# P5.1 Family UX and Usability Audit

Status: first D1 audit and remediation pass completed on 2026-08-21.

## Audience and acceptance standard

The primary family experience must work for non-technical relatives on a phone without requiring knowledge of hierarchy, governance or platform terminology. People, relationships, photos, memories and important moments come before configuration and statistics.

## Audited journeys

- First-time family setup at 1440×1000 and 390×844.
- 150-member family-tree landing experience.
- Mobile family directory and profile discovery.
- Family-wide timeline and empty state.
- Mobile navigation, contribution entry point and horizontal overflow.

## Findings remediated

- Replaced generic-first setup with a warm family-first entry; other verticals remain available through progressive disclosure.
- Reframed starting choices as building together, exploring a demo, or bringing existing records.
- Added a family welcome panel with people, generation and connection context.
- Changed family-facing labels from hierarchy/network language to Family Tree, Family Directory, Family Profile, Our Family Story and Add Relative.
- Made the mobile contribution action reachable in the top bar.
- Repaired six-item mobile navigation wrapping by making it a single horizontally scrollable row.
- Added guidance for large trees, where fitting 150 people makes cards unreadable until a branch is focused.
- Changed recurring birth records to the user-facing label Birthday.
- Added a warm, actionable timeline empty state.
- Raised profile drawers above mobile navigation and added bottom clearance.
- Added an accessible close label and friendly long-form birth dates.
- Corrected private-contact presentation so shared-mode contact visibility follows viewer role/ownership instead of always presenting as permitted.
- Reset scroll position after setup and confirmed there is no mobile horizontal page overflow.

## Remaining D1 UX work

- Test with real family photos, missing data and much longer Indian names.
- Add guided find/claim/contribute journeys and contextual completion prompts in P5.2.
- Validate tree navigation with older and first-time users; consider a branch-first mobile default if testing confirms full-tree overview is confusing.
- Complete live Supabase member/admin/invited-user usability journeys alongside the RLS matrix.
- Establish reusable loading, error, success and offline patterns.

## Verification

Playwright-driven visual checks covered setup, tree, directory/profile and timeline on desktop/mobile. TypeScript, production build and demo integrity validation must remain green for release.
