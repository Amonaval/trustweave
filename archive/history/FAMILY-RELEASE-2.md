# Family Release 2 — Remember, Connect and Celebrate

## Product promise
Release 2 turns the directory into a warm family place worth revisiting. The product should answer three questions immediately: what is happening in my family, what should I remember, and how can I help?

## UI-visible missions
1. **Return Home** — new mobile-first Home experience with recent memories, upcoming birthdays and one small contribution prompt. Empty/loading/error states remain calm and family-friendly.
2. **Memories & stories** — photo + short story flow stays WhatsApp-simple; migration `017` allows a memory to be connected to multiple relatives. Private/admin media continues through signed authorization.
3. **Living moments** — existing life-event timeline and upcoming milestone engine remain the verified source; Home surfaces the useful subset rather than creating a noisy social feed.
4. **Guided contribution** — existing deterministic contribution engine is promoted from an admin-looking utility into a return-home action. No invented family facts.
5. **Sharing** — D1 privacy-safe profile QR, invitations and public links remain the base for WhatsApp-first distribution. Rich memory/greeting preview cards are the next visual iteration, not a reason to weaken privacy.
6. **Gatherings** — existing groups/reunions RSVP flow remains lightweight and connected to the family experience.
7. **Notifications** — migration `017` adds restrained per-user preferences. Birthdays, anniversaries, invitations and gatherings default on; memories and contribution nudges default off.

## UI-visible delivery rule
Every mission must identify changed journey/screens, newly possible user action, mobile and translated behavior, all states, visual verification, accessibility/performance acceptance, realistic family-user test and privacy impact in plain language.

## Acceptance
- 360/390/430 px mobile, tablet and desktop review.
- English, Hindi and Marathi core return journey.
- Keyboard-visible controls, labelled actions, readable contrast and no horizontal page overflow.
- Useful at 150–500 members; large tree remains focused/progressive rather than rendered as one giant canvas.
- No developer-style copy or dead controls.
- A non-technical relative can share a memory, find a birthday and complete one contribution without explanation.
- Final question: **Would I confidently send this link to grandparents, cousins and extended family today?**

## Privacy in plain language
A family memory is not public merely because it contains a photo. Members choose its visibility; media remains protected by the existing signed-media rules. Tagging a relative links the memory to that profile but does not reveal private contact details. Notification preferences control nudges, not access rights.

## Exit condition
Members return for family moments, contribute information or memories, and naturally share the product with other relatives. Platform extraction, tenancy, billing and enterprise expansion stay paused until real-family usage validates this loop.
