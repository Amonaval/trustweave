# P4.4 — Intelligence, Geography, Export & Scale

P4.4 is the final P4 iteration and is built directly on the corrected P4.3 baseline.

## Implemented

### Server-side discovery
- Added `search_family_members(...)` RPC.
- Supports query, profession, city, generation and living/deceased filters.
- Enforces profile/contact visibility before returning rows.
- Caps page size at 500 and supports offset pagination.
- Repository exposes the search boundary for future graph-windowing.

### Network intelligence
- Admin analytics RPC provides member, living/deceased, relationship, mapped, memory and life-event counts.
- Generation, city and profession distributions.
- Admin UI includes a compact Network Intelligence panel.
- Analytics can be exported as JSON.

### Geography
- Added server-side city/country summary with averaged city coordinates.
- Existing city-level privacy model is preserved.
- No raw private location data is exposed through the summary RPC.

### Export
- Existing CSV/JSON exports retained.
- Added standalone SVG hierarchy export.
- Added browser print / Save as PDF path so no server-side PDF dependency is required.

### Scale direction
- Server-side discovery is now available behind the repository boundary.
- Pagination is built into the RPC.
- Full graph hydration remains compatible with the current tree for existing networks; future very-large-network work can switch the tree to graph-windowed loading without changing the repository contract.

### Mobile / PWA
- Existing mobile bottom navigation and responsive P4 features are preserved.
- Existing manifest remains usable as an installable web app descriptor.

## Migration

For an existing P4.3 database, run only:

`supabase/migrations/009_p4_4_intelligence_scale.sql`

P4.3 migration `008_p4_3_community_discovery.sql` has also been corrected to explicitly drop the previous `review_change_request(uuid,varchar,text)` before changing its return type. This is required because P4.1 defined that function as `returns public.change_requests` while P4.3 changed it to `returns uuid`.
