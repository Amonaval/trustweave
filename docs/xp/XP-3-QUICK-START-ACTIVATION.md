# XP-3 — Quick Start & Activation Parity

Status: **source-complete; staging/browser verification pending**.

A shared Quick Start registry now configures activation jobs for every released vertical. Productized verticals and Alumni render the same role-aware progress component; Family keeps its mature Quick Family Start while participating in the shared registry contract.

Quick Start state is persisted per network/user, can be dismissed and resumed, and combines explicit progress with live signals. Every action routes to an existing working surface or editor rather than a decorative placeholder.

Housing Society: import units/residents, add property, invite, publish notice. Alumni: self/cohort/invite/import. Organization: self/team/project/invite/import. Franchise: branch/operator/geography/import. Business Trust: business/partner/circle/import. Professional: profile/expertise/invite/import. Association and Family Association have equivalent vertical-specific jobs.
